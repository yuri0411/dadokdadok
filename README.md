## 프로젝트 소개
다독다독은 JLPT 시험을 준비하면서 단어를 효율적으로 반복 학습(회독) 할 수 있도록 만든 개인 프로젝트입니다.  
서비스명인 다독다독은 **많이 읽고, 여러 번 다시 본다**는 학습 방향성을 담고 있습니다.

### OpenAPI 클라이언트 생성

서버의 Swagger 문서를 기준으로 API 함수, React Query 훅, TypeScript 타입을 생성합니다.

```bash
# 배포된 서버의 /api/docs-json 기준
yarn api:generate

# 같은 상위 폴더의 jlpt-voca-server/swagger.json 기준
yarn api:generate:local
```

생성 결과는 `src/services/generated`에 저장되며 직접 수정하지 않습니다.


### 프론트엔드 개발 환경 및 구조
이 프로젝트는 React 기반 환경에서 컴포넌트 단위로 학습 UI를 구성하고,
상태 변화에 따라 학습 진행과 회독 상태가 자연스럽게 화면에 반영되도록 구현했습니다.

TypeScript를 활용해 코드의 안정성과 유지보수성을 높였으며,
Zustand를 사용해 학습 데이터를 전역으로 관리하고,
다시 볼 단어, 학습 완료 단어, 누적 학습 시간 등의 학습 기록을
로컬 스토리지에 저장하여 새로고침 이후에도 학습 상태가 유지되도록 했습니다.

데이터 패칭은 React Query를 사용하여
단어 목록과 같은 서버 데이터를 클라이언트 상태와 분리해 관리했으며,
캐싱을 통해 불필요한 네트워크 요청을 줄이고 로딩 상태를 일관된 방식으로 처리할 수 있도록 구현했습니다.

공통 컴포넌트는 UI 라이브러리에 의존하지 않고 직접 구현했으며,
필요한 컴포넌트만 컴포넌트 단위로 캡슐화하여
스타일 충돌 없이 일관된 UI를 관리할 수 있도록 설계했습니다.

## 🤖 AI 활용과 개발 검증

다독다독은 사용자에게 학습 분석을 제공하는 기능과, AI가 프로젝트 규칙에 따라 구현하고 결과를 검증하도록 돕는 개발 환경을 함께 구성하고 있습니다.

### 서비스 기능: AI 학습 분석

홈의 **AI 학습 분석** 카드는 학습 상태를 `POST /api/study-insights`로 전달하고, 서버가 반환한 학습 요약과 다음 행동 제안을 표시합니다.

- 전달 정보: 레벨·단원, 목표 단어 수, 학습한 단어 수, 다시 볼 단어 수, 회독 수, 레벨별 누적 학습 시간
- 화면 상태: 학습 기록 없음, 분석 중, 분석 결과, 요청 실패
- 서버 응답과 캐시는 React Query로 관리하며, 학습 기록은 Zustand의 클라이언트 상태와 구분합니다.

전달하는 학습 시간은 당일 시간이 아닌 **레벨별 누적 시간**입니다. 이 프론트엔드 저장소는 분석 API 연동을 담당하며, 실제 AI 모델·프롬프트·서버 운영 정책은 백엔드 구현에서 확인해야 합니다.

관련 코드: [학습 분석 카드](src/pages/Home/components/StudyInsightCard.tsx), [분석 API](src/services/studyInsight/api.ts), [조회 및 캐시 설정](src/services/studyInsight/queries.ts)

### 하네스: 구현 결과를 확인하는 자동 검증

AI가 규칙을 읽는 데서 그치지 않도록, 일부 규칙을 ESLint와 테스트로 검사합니다. 이 검사는 AI와 사람이 작성한 코드 모두에 적용됩니다.

| 검증 영역 | 적용 내용 |
|---|---|
| API 접근 경계 | UI·hooks·store·utils에서 HTTP 클라이언트와 생성 API를 직접 가져오는 것을 차단 |
| 컴포넌트 의존성 | 공통 컴포넌트가 페이지에 의존하는 것을 차단 |
| 동작 및 데이터 | UI 접근성·상호작용, 학습 기록·회독·복습·시간 누적·저장 복원 검증 |
| PR 병합 | GitHub Actions의 `lint`, `typecheck`, `test`, `build` 통과를 main 보호 규칙의 필수 조건으로 적용 |

로컬 통합 검증은 다음 명령으로 실행합니다.

```bash
yarn verify
```

Storybook 관련 파일을 변경한 경우에는 `yarn build-storybook`도 실행합니다. CSS 토큰 사용 전체와 실제 브라우저의 모든 사용자 흐름을 자동 검사하는 단계까지 구현된 것은 아닙니다.

### 디자인 연결: Figma MCP

Figma 원격 MCP를 통해 디자인 정보를 개발 작업에 참고할 수 있도록 프로젝트 전용 Codex 설정을 준비했습니다. 설정은 [PR #4](https://github.com/yuri0411/dadokdadok/pull/4)의 `.codex/config.toml`에 있으며, 서버 주소는 `https://mcp.figma.com/mcp`입니다.

개발 환경에서 OAuth 인증을 완료했으며, 인증 정보는 저장소에 포함하지 않습니다. 다른 개발자는 설정이 포함된 브랜치의 프로젝트 폴더에서 `codex mcp login figma`로 본인 계정을 연결해야 합니다. 아직 MCP를 이용한 화면 구현이나 Figma와 코드의 자동 동기화는 적용하지 않았습니다.

## ⭐ 주요 기능

### 1️⃣ JLPT 레벨별 단어 제공
- JLPT **N5 ~ N1** 전 레벨 지원
- 레벨별 → 단원별(50개 단위) 구성으로 체계적인 학습 가능

### 2️⃣ 회독 기반 단어 학습
- 단어를 보고 알면 👉 **외웠어요**
- 헷갈리면 👉 **다시 볼래요**
- 단원 종료 후 **헷갈린 단어만 랜덤 순서로 복습**
- 학습 흐름이 끊기지 않도록 자연스러운 회독 동선 제공

### 3️⃣ 누적 학습 데이터 관리
- 누적 학습 시간 자동 저장
- 회독 수 기록
- 레벨·단원별 학습 현황 관리
- 학습 흐름을 한눈에 확인 가능

### 4️⃣ 학습 동기부여 기능
- 학습 완료 시 부드러운 응원 문구 제공
- 꾸준한 학습을 돕는 긍정적인 피드백 경험

---

## 📚 학습 흐름은 이렇게 진행돼요

1. 학습하고 싶은 **JLPT 레벨 선택 (N5 ~ N1)**
2. **50개 단위로 구성된 단원 선택**
3. 단어 카드를 간단히 분류
    - 👉 알고 있는 단어: **오른쪽 (외웠어요)**
    - 👉 헷갈리는 단어: **왼쪽 (다시 볼래요)**
4. 단원 종료 후 **헷갈렸던 단어만 랜덤 복습**
5. 모든 단어를 완료하면  
   총 학습 시간, 회독 수, 단원 상태를 모달로 안내
6. 학습 종료 시에도  
   누적 기록과 응원 문구가 담긴 모달 제공

> **전체 과정은 단순하지만 집중이 잘되는 회독 흐름**으로 구성되어 있습니다.

## 🎯 이런 학습 효과를 기대할 수 있어요

✅ **반복 회독 기반의 확실한 암기**

한번 보면 잊어버리기 쉬운 단어들을 반복 회독 구조로 자연스럽게 익히도록 도와줍니다.

✅ **헷갈리는 단어 중심의 집중 복습**

다독다독의 핵심은 오답 중심 복습 알고리즘입니다. 사용자가 헷갈렸던 단어들만 모아 다시 보여주기 때문에 짧은 시간에도 집중적으로 단어 실력을 올릴 수 있어요.

✅ **누적 기록이 주는 꾸준함의 동기부여**

학습 시간이 눈에 보이고, 각 단원에 진도가 누적되기 때문에 사용자가 스스로 성장하는 느낌을 경험할 수 있어요.

✅ **실전 JLPT 시험 대비에 직접적인 도움**

회독 기반 학습은 실제 시험에서 단어가 떠오르는 속도와 안정감을 높여 독해/문법/청해 전반의 점수 향상에 직접적인 도움이 됩니다.
